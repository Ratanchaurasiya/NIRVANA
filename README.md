## 🌟 Overview

**NIRVANA GROUP** is a world-class real estate development and investment holding company delivering Grade-A commercial office environments and luxury residential estates across Gujarat's prime growth corridors (Science City, Sola, SG Highway, Ahmedabad).

This repository features both:
1. **Modern Frontend App**: React 19, Tailwind CSS v4, Lucide Icons, Three.js 3D interactive wireframes, and responsive luxury UI.
2. **Enterprise Core PHP Suite** (`php_project/`): Standalone Core PHP 8.x + MySQL with PDO prepared statements, admin CMS, dynamic project catalog, Instagram reels integration, and secure customer enquiry pipeline.

## 🚀 Quick Start

### 1. React Frontend
```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Production build
npm run build
```

### 2. PHP & MySQL Suite (`php_project/`)
- Place in your Apache `htdocs` directory (e.g. `XAMPP/htdocs/nirvana`).
- Import `php_project/database.sql` into MySQL.
- Configure credentials in `php_project/includes/config.php`.
- Access via `http://localhost/nirvana/`.
